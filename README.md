## 📘 Descripción general del sistema

Proyecto desarrollado en Java utilizando NetBeans, JDBC y MySQL.
Sistema de gestion para la empresa SpeedFast que permite registrar
pedidos, repartidores y entregas, almacenando la informacion en una base de datos MySQL.

---

## 🧱 Estructura general del proyecto

```plaintext
📁src/

    -ui

        EntregaDAO.java
        
    -conexion
````

## ⚙️ Instrucciones de funcionalidad:

1. Registrar pedidos.
2. Registrar repartidores.
3. Registrar entregas.
4. Consultar los pedidos registrados.
5. Visualizar los pedidos mediante un JTable.
6. Almacenar registros en MySQL.
7. JDBC para conectar la aplicacion con la base de datos.
8. Clases DAO para las operaciones con la base de datos.
9. Utilizar clases modelo para representar pedidos, repartidores y entregas.
10. Utilizar una interfaz grafica desarrollada con Java Swing.

---

## ⚙️ Instrucciones de uso:

1. Abrir el proyecto en Apache NetBeans.
2. Configurar la conexion a MySQL en ConexionDB.java.
3. Crear la base de datos speedfast_db y sus respectivas tablas.
4. Ejecutar la clase Main.java.
5. Registrar un pedido utilizando el formulario correspondiente.
6. Registrar un repartidor.
7. Seleccionar un pedido y un repartidor para registrar una entrega.
8. Consultar los pedidos registrados en la tabla de la interfaz grafica.
